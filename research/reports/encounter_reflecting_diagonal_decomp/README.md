# Reflecting Encounter Diagonal Decomposition

This report runs a bounded mobility-ratio scan for the reflecting-boundary
two-walker encounter model using diagonal-position contributions.

Run:

```bash
python research/reports/encounter_reflecting_diagonal_decomp/code/run_ratio_scan.py
```

The scan uses `rho in [0.1, 0.2, 0.5, 1, 2, 5, 10]` with fixed total mobility,
four initial pairs on `L=7`, and validates both mass balance and
`f_E(t)=sum_k f_k(t)` for every case.

Outputs are written to `artifacts/{data,outputs,figures,tables}/`; the root
`data/`, `outputs/`, `figures/`, and `tables/` entries are symlinks kept for
script compatibility. `notes/SUMMARY.md` is regenerated by the scan script.

## Green-Formula Comparison

Run:

```bash
python research/reports/encounter_reflecting_diagonal_decomp/code/compare_green_formula.py
```

This small `L=5`/`L=7` check compares the absorbing-chain encounter generating
function `F_E(z)=z alpha (I-zM)^(-1) R 1` with the matching multi-target
Green/renewal formula evaluated on the same reflecting lazy product chain.
It writes `data/green_formula_comparison.csv`,
`outputs/green_formula_comparison_summary.json`, and
`notes/green_formula_comparison.md`.
