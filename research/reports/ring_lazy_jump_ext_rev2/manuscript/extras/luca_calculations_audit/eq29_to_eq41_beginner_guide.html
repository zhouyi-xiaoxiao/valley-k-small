0. 一句话结论

Luca 新稿不是全错，也不是全对。最前面的 stochastic shortcut sign 已经修到了 Eq. (29)-(31)， 但这个修正没有一致传到 first-passage 部分。第一个真正的硬错误在 Eq. (32): 分母应该是 \(1+z\beta(1-q)\widetilde W_u(u,z)\)，不是减号。

从这个错误往下，Eq. (33) 的整体符号、Eq. (40) 的卷积符号、Eq. (41) 的长展开和最后的 \(t\alpha_1^t\) tail 结论都会被影响。最干净的正确版本不是继续保留 Eq. (41) 那个长串， 而是把对称 antipodal 情形整理成一个 closed form。

\[ \boxed{ \widetilde F_\rho(z)= \frac{ aT_{L-\rho}(y)+U_{\rho-1}(y)+U_{L-\rho-1}(y)} {aT_L(y)+U_{L-1}(y)} } \] \[ N=2L,\qquad a=\frac{q}{\beta(1-q)},\qquad y=1+\frac{1/z-1}{q}. \]

这条式子是 corrected Eq. (41) 最应该收敛到的形状。它直接告诉我们尾部 decay 由 \(aT_L(y)+U_{L-1}(y)=0\) 的最大正根 \(s_1=1-q+qy_1\) 控制。

1. 先把符号翻译成人话

\(P\) 没有吸收点、没有 shortcut 的普通 ring propagator。此时 \(v\) 只是普通节点。
\(W\) 有吸收点 \(v\)、但还没有 shortcut 的 killed/absorbing propagator。此时 \(v\) 不再是普通节点。
\(S\) 加上 shortcut 后的 propagator。这里真正要比较的是 \(S\) 和 finite stochastic shortcut matrix。

为什么 \(v\) 不是普通节点？

因为这一段已经进入 “one absorbing site” 的问题。目标是 first passage to \(v\)。 一旦走到 \(v\)，first-passage event 已经发生，后面不继续在 transient space 里传播。

所以在 \(W\) 里，\(v\) 是 absorbing/killing boundary，而不是普通 ring 节点。 这就是原文 line 396 说 \(m=v\) 时 \(\widetilde W_v(n,z)=0\) 的背景。

shortcut 到 \(v\) 是什么？

概率守恒的原始 ring 里，shortcut 是把 \(\lambda=\beta(1-q)\) 从 \(u\to u\) self-loop 搬到 \(u\to v\)。

但如果 \(v\) 是 absorbing target，那么 \(u\to v\) 在 transient dynamics 中就是从 \(u\) 杀掉这部分概率。这不是“走到普通节点 \(v\) 后继续走”，而是“first passage 完成”。

最小直觉: shortcut 增加了更早命中 \(v\) 的机会，所以 survival 应该减少，first-passage probability 应该增加。 这就是 Eq. (32) 最终应该出现正的 correction term 的原因。

2. Luca 这段推导想做什么

1
Eq. (29): 用 rank-one defect 公式写 “有一个 shortcut 的 propagator”。 这是 resolvent/Sherman-Morrison 类型技巧。
2
Eq. (30)-(31): 把普通 ring propagator \(P\) 换成 absorbing propagator \(W\)， 再令 absorbing target 就是 shortcut destination: \(m=v\)。
3
Eq. (32)-(33): 对所有非吸收节点求和，把 propagator 变成 survival， 再用 survival 和 first passage 的关系得到 \(\widetilde F\)。
4
Eq. (34)-(35): 定义一个 \(H\)，把反复从 \(u\) 附近等待/shortcut 的部分打包。
5
Eq. (38)-(41): 把 \(H\)、\(W\)、\(\mathcal F\) 都展开成 mode，然后在时间域做卷积。 这一步会变成长串，也最容易把中间 pole 当成真正的最终 decay。

4. 为什么 Eq. (32) 是第一个硬错误

从 corrected Eq. (31) 开始:

\[ \widetilde S_{n_0}(n,z) = \widetilde W_{n_0}(n,z) - \frac{z\lambda\widetilde W_{n_0}(u,z)\widetilde W_u(n,z)} {1+z\lambda\widetilde W_u(u,z)}, \qquad \lambda=\beta(1-q). \]

对所有 transient 节点 \(n\) 求和。因为 \(\sum_n \widetilde W_r(n,z)\) 是 survival generating function， 所以

\[ \sum_n \widetilde W_r(n,z) = \frac{1-\widetilde{\mathcal F}_r(v,z)}{1-z}. \]

代进去:

\[ \frac{1-\widetilde F_{n_0}(v,z)}{1-z} = \frac{1-\widetilde{\mathcal F}_{n_0}(v,z)}{1-z} - \frac{ z\lambda\widetilde W_{n_0}(u,z)} {1+z\lambda\widetilde W_u(u,z)} \frac{1-\widetilde{\mathcal F}_u(v,z)}{1-z}. \]

两边乘以 \(1-z\)，再把 \(F\) 移到左边，就得到:

\[ \boxed{ \widetilde F_{n_0}(v,z) = \widetilde{\mathcal F}_{n_0}(v,z) + \frac{ z\beta(1-q)\widetilde W_{n_0}(u,z) [1-\widetilde{\mathcal F}_u(v,z)] } {1+z\beta(1-q)\widetilde W_u(u,z)} }. \]
注意两个 plus: correction term 是 plus，分母也是 plus。Luca 新稿 Eq. (32) 里 correction term 前面是 plus， 但分母仍写成了 \(1-z\beta(1-q)\widetilde W_u(u,z)\)，所以还没有完全从 Eq. (31) 传播过来。

5. Eq. (33) 和 \(H\): 符号应该怎么跟

Luca 定义的 \(H\) 在新版里是:

\[ \widetilde H_{N,|u-v|}(z) = \frac{\beta(1-q)}{q} \frac{1}{1+z\beta(1-q)\widetilde W_u(u,z)}. \]

所以 Eq. (32) 里的系数可以直接换成

\[ \frac{z\beta(1-q)} {1+z\beta(1-q)\widetilde W_u(u,z)} = qz\,\widetilde H_{N,|u-v|}(z). \]

因此 Eq. (33) 必须是:

\[ \boxed{ \widetilde F_{n_0}(v,z)= \widetilde{\mathcal F}_{n_0}(v,z) + qz\widetilde W_{n_0}(u,z) [1-\widetilde{\mathcal F}_u(v,z)] \widetilde H_{N,|u-v|}(z). } \]
Eq. (35) 的 \(\widetilde H_{N,N/2}(z)=1/(q/[\beta(1-q)]+\phi(z))\) 与这个定义一致。 问题不是 \(H\) 本身，而是 Eq. (33) 使用 \(H\) 时前面的符号没有改过来。

6. Eq. (40): 生成函数的 plus 到时域仍然是 plus

Eq. (33) 是三个 generating functions 的乘积: \(z\widetilde W_{n_0}(u,z)\)、\(1-\widetilde{\mathcal F}_u(v,z)\)、\(\widetilde H(z)\)。 乘积变回 time domain 时就是卷积。符号不会在这一步自己翻转。

\[ \boxed{ F_{n_0}(v,t)=\mathcal F_{n_0}(v,t) +q\sum_{t'=0}^{t-1}W_{n_0}(u,t-1-t') \sum_{t''=0}^{t'} [\delta_{t',t''}-\mathcal F_u(v,t'-t'')] H_{N,N/2}(t''). } \]
Luca 新稿 Eq. (40) 仍然写了 minus。这个 minus 是 Eq. (33) 旧符号的遗留。

7. Eq. (41) 正确应该长什么样

Eq. (41) 的原路线是: 把 \(W\) 展开成 \(\alpha_\ell,\gamma_r\)，把 \(H\) 展开成 \(s_k\)， 再把所有卷积手算出来。这个路线不是不能走，但它会产生很多中间项，容易把中间 mode 当成最终 pole。

对称 antipodal 情形最清楚的修正版，是直接写 closed form。这里令 \(N=2L\)，target \(v=0\)， shortcut \(u=L\to0\)，\(\rho\) 是起点 \(n_0\) 到 target 的折叠距离，\(0\le\rho\le L\)。
\[ \boxed{ \widetilde F_\rho(z)= \frac{ aT_{L-\rho}(y)+U_{\rho-1}(y)+U_{L-\rho-1}(y)} {aT_L(y)+U_{L-1}(y)} }, \] \[ a=\frac{q}{\beta(1-q)},\qquad y=1+\frac{1/z-1}{q},\qquad U_{-1}(y)=0. \]

如果要把它变成 time-domain 的 Eq. (41)，设

\[ D(y)=aT_L(y)+U_{L-1}(y),\qquad N_\rho(y)=aT_{L-\rho}(y)+U_{\rho-1}(y)+U_{L-\rho-1}(y). \] \[ D(y_k)=0,\qquad s_k=1-q+qy_k. \]

对 simple roots，partial fraction 给出:

\[ \boxed{ F_\rho(t)=\sum_k B_{\rho k}s_k^{t-1}, \qquad B_{\rho k}= \frac{q\,N_\rho(y_k)}{D'(y_k)} } \qquad (t\ge1). \]

这才是我建议替换 Eq. (41) 的“完整正确形状”。它没有 \(\alpha_\ell^t t\) 这种 generic 项， 因为这些 apparent \(\alpha,\gamma\) poles 在完整 closed form 里已经取消。

如果硬修 Luca 那条长串，会是什么样？

如果只是为了对应原来的长卷积结构，不能只把 minus 改成 plus。还必须把 \(H(0)=h_0\) 单独拿出来，因为 \(H\) 的 partial fraction 有一个常数项。 下面这个才是“走原路线”的完整硬修形状。它不是推荐最终稿，但可以帮助看出原来的 Eq. (41) 应该朝哪个方向改。

\[ h_0=H(0)=\frac{\beta(1-q)}{q}=\frac1a,\qquad H(c)=\sum_k c_k s_k^{c-1}\quad(c\ge1) \] \[ A^{(+)}_t(x;s)=\frac{s^{t-1}-x^{t-1}}{s-x},\qquad B^{(0)}_t(x,y)=\frac{x^{t-1}-y^{t-1}}{x-y} \] \[ B^{(+)}_t(x,y;s)= [z^{t-3}] \frac{1}{(1-zx)(1-zy)(1-zs)}. \]
\[ \begin{aligned} F_{n_0}(v,t) &= \sum_{\ell=1}^{L}f_\ell(n_0,v)\alpha_\ell^{t-1} \\ &\quad +qh_0 \left[ \sum_r G^{(1)}_r(n_0,u,v)\gamma_r^{t-1} + \sum_r g^{(2)}_r(n_0,u,v)\alpha_r^{t-1} \right] \\ &\quad +q\sum_k c_k \left[ \sum_r G^{(1)}_r(n_0,u,v)A^{(+)}_t(\gamma_r;s_k) + \sum_r g^{(2)}_r(n_0,u,v)A^{(+)}_t(\alpha_r;s_k) \right] \\ &\quad -qh_0\sum_\ell f_\ell(u,v) \left[ \sum_r G^{(1)}_r(n_0,u,v)B^{(0)}_t(\gamma_r,\alpha_\ell) + \sum_r g^{(2)}_r(n_0,u,v)B^{(0)}_t(\alpha_r,\alpha_\ell) \right] \\ &\quad -q\sum_k c_k\sum_\ell f_\ell(u,v) \left[ \sum_r G^{(1)}_r(n_0,u,v)B^{(+)}_t(\gamma_r,\alpha_\ell;s_k) + \sum_r g^{(2)}_r(n_0,u,v)B^{(+)}_t(\alpha_r,\alpha_\ell;s_k) \right]. \end{aligned} \]
这条“硬修版”保留了 \(\alpha,\gamma,s\) 三套中间 modes，所以不适合作为 tail 结论的最终依据。 它应该能化简回上面的 closed form。最终 pole 只需要看 \(D(y)=0\)。

8. “互相取消”、closed form、最后 decay 到底是什么

什么叫互相取消？

长展开里会出现 \(\alpha_\ell\)、\(\gamma_r\)、\(s_k\) 的分母。 但这不代表它们都是真正的最终 decay。把所有项合起来以后，某些分母的 numerator 也有相同因子， 所以 pole 被约掉了。

\[ \frac{1-\alpha z}{(1-\alpha z)(1-sz)} = \frac{1}{1-sz}. \]

closed form 是什么？

closed form 不是近似。它是把所有中间求和和卷积整理成一个明确的分子除以明确的分母。 一旦有 closed form，真正的 decay 就看这个最终分母的 roots。

\[ \widetilde F_\rho(z)=\frac{N_\rho(y)}{D(y)}. \]

最后 long-time tail 是:

\[ \boxed{ F_\rho(t)\sim B_{\rho1}s_1^{t-1}, \qquad \frac{F_\rho(t+1)}{F_\rho(t)}\to s_1. } \] \[ \boxed{\tau_\beta^{-1}=-\log s_1.} \]

这里确实有 beta 依赖。依赖方式是:

\[ aT_L(y_1)+U_{L-1}(y_1)=0,\qquad s_1=1-q+qy_1,\qquad a=\frac{q}{\beta(1-q)}. \]

等价地，写 \(y_1=\cos\theta_1\):

\[ \tan(L\theta_1)=-a\sin\theta_1, \qquad s_1=1-q+q\cos\theta_1. \]
结论: decay 依赖 \(N,q,\beta\)。起点 \(\rho\) 主要影响振幅 \(B_{\rho1}\)，一般不改变主 decay rate \(s_1\)。 double peak 是 finite-time shape 问题，不是只看 tail decay 就能判定的。

弱 shortcut 时可以看得更直观:

\[ s_1=\alpha_1-\frac{2\beta(1-q)}{N} +O([\beta(1-q)]^2), \] \[ 1-s_1 \sim \frac{q\pi^2}{2N^2} +\frac{2\beta(1-q)}{N}. \]
